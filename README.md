# LearnPython

Python practice scripts covering variables, conditions, functions, data structures, file handling, OOP, and modules.

These files are learning notes, not a library. Run any script from this folder:

```bash
python CWM_01_Variable_DataTypes.py
```

`CWM_` in the filenames is a lesson prefix (Code With Manoj / course modules). Files ending in `_p` are extra practice problems.

Sample JSON files (`data.json`, `user.json`, `empData.json`) and `sample.txt` are dummy examples used by the file-handling lessons.

## Layout

| File | Topic |
| --- | --- |
| `CWM_01`–`CWM_02` | Variables and data types |
| `CWM_03`–`CWM_04` | Conditions |
| `CWM_05`–`CWM_06` | Functions |
| `CWM_07`–`CWM_08` | Data structures |
| `CWM_09`–`CWM_10` | File handling and JSON |
| `CWM_11` | Object-oriented Python |
| `CWM_12`–`CWM_13` | Modules and imports |
| `git-practice/` | Git notes from a merge-practice exercise |
